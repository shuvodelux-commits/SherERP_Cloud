# SherERP Cloud

Cloudflare Workers + D1 SQLite migration workspace for the existing SherERP/Mohim ERP.

- **Source of truth:** [Mohim_ERP](https://github.com/shuvodelux-commits/Mohim_ERP) (Google Apps Script + Google Sheets).
- **Target:** Cloudflare Workers + D1 (SQLite), with the existing HTML/CSS/JavaScript interface and business behavior preserved.
- **Status:** Planning only. No application migration, D1 database, or deployment is complete.
- **Safety:** Do not modify or delete the source repository or live Google Sheets during migration.

The detailed phased migration plan, source inventory, and agent instructions will be proposed in reviewable pull requests before implementation begins.
