## Internal function contract
`planMultiUnitPosLine({productId,unitBreakdown,claimedBaseQty,shortageMode},{products,conversionRows,stockLots})` accepts tenant-scoped, server-trusted product, active conversion and lot snapshots from a *future* M03/M04 caller. It NEVER trusts browser-claimed factor, unit price, product name, unit name or line total. It refuses absent/ambiguous/deleted/inactive product, duplicate active conversion IDs, malformed factor, duplicate lot IDs, invalid or mismatching unit breakdown/claimed base quantity, unsupported Bundle, and unreviewed shortage mode. `shortageMode` must be explicitly `Own`, `Negative`, or `Vendor`. `Own` requires sufficient FIFO owned stock; with shortfall, it refuses and caller can seek explicit Negative or Vendor selection. `Negative` retains source FIFO draws and marks uncovered base quantity as a negative-stock intent; `Vendor` uses frozen vendor sourcing planner and marks uncovered base quantity as vendor-sourcing intent. In all cases no inventory, payable, cost, ledger or Cash/Bank record is written. A legacy (empty) breakdown preserves original base quantity and FIFO sale price calculations without synthesizing conversion history.

**Output (pure and read-only):** `{productId,stockUnit,baseQty,shortageMode,unitBreakdownSnapshot,unitPricingSnapshot,unitPrice,lineTotal,fifoDraws,shortfallBaseQty}`. Historial unit factor/quantity and independent unit-price snapshots are retained for future immutable `SALE_ITEMS` writers but not persisted by this code. Each returned FIFO draw has only `lotId` and `baseQty` — **never purchase cost**, which belongs to separate permission-controlled profit previews. Original single-unit invoices stay unchanged. `lineTotal` is authoritative for proposed price display; `unitPrice` is rounded effective base price, not permission to recompute invoice totals as `baseQty*unitPrice`. No production posting or public route may consume this as authority without D1-stored immutable conversion revision, M05/M03 stock lock, M04 session, Cash Session, SQL replay, rollback and accounting evidence.
