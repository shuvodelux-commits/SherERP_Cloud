## Problem
Frozen `SALES_DRAFTS.Items JSON` serializer only preserves the legacy Product/Name/Unit/Qty/UnitPrice/LineTotal, bundle/vendor/serial/warranty fields. It **intentionally drops** new POS business evidence (unitBreakdownSnapshot, unitPricingSnapshot, actualSqft, measurementSnapshot, unitRevision, source FIFO, lineAmountMinor and selected Sqft price). Silently sending such a line through source-ported `validateSaleDraftPayload` would create a draft with irrecoverable original unit/measurement price evidence. No M02/M03 versioned persisted contract has been signed off yet; this PR must not invent one or modify source behavior.

## New narrow read-only preflight
`prepareLosslessLegacySaleDraft(payload,trusted)` accepts plain, accessor-free legacy draft input, a server-derived trusted settings+Bank Account snapshot, then **delegates unchanged** to the original `validateSaleDraftPayload`. Return `{draftFormat:'legacy',candidate: originalCleanResult,postingAllowed:false}`. It refuses any extra top-level or item-level data fields not retained by source serialization; especially new unit/Tiles/FIFO source snapshots and nonlegacy tender metadata. It must not reconstruct ratios from today's product price, coerce a Tile to generic Sqft or set a fabricated Unit revision. For valid legacy source drafts, output must match the unmodified port byte-for-byte for `Items JSON`/`Payment JSON` and all original fields. Failures are explicit `NEEDS_REVIEW: versioned unit-aware draft snapshot required` or `NEEDS_REVIEW: legacy draft field would be discarded`. Saved serial/warranty and original bundle/vendor fields must remain legitimate. This cannot authorize any write; M03 must implement SQL-backed versioned draft storage and auth later.

**Scoped additive files only:** `src/modules/m06-legacy-draft-loss-guard.js`, `tests/m06-legacy-draft-loss-guard.test.mjs`, this M06 plan. No edits to `src/modules/sale-draft-payload.js`, source GAS, `src/db`, D1 migrations, `src/rpc`, shared posting kernel, Worker bindings, M05 conversion or M07 reversal. No public RPC registration or production transaction.
