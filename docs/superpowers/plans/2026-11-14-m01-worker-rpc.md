> For agentic workers: apply Superpowers executing-plans, test-driven-development and verification-before-completion to this bounded slice.

**Goal:** Assemble the untouched legacy UI into static assets, replace only the generated page's central serverCall transport, and supply a fail-closed Worker API shell. **No business RPC is activated.**

**Spec:** `docs/MIGRATION_PLAN.md`, M01 in `docs/WORKSTREAMS.md`, and `docs/superpowers/plans/2026-11-14-m01-static-frontend.md`.

**Source:** `legacy/source/javascript.html` from immutable Mohim_ERP commit `29aa4a5c7a7062a49e6bf4758beda3a8d62d9ff2`.

## Global constraints
- Preserve all original HTML/CSS/JS partial source bytes, DOM IDs and invoice print rules.
- Never connect current browser RPCs to Google Sheets or live GAS.
- Return 501 until real authentication, authorization, D1 repository and individual business handlers are ported and verified.
- No Cloudflare deployment, D1 creation or secrets in this PR.
- Keep assets first for normal paths and Worker first for /api/*, with no unknown /api path falling through to the SPA.
- Generate worker-ready built HTML by replacing exactly one known legacy `function serverCall(fnName)` block and refusing unknown source patterns.
